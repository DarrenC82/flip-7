## Project Overview

The **Flip 7** project is a personal learning and development exercise by **Darren Charlton**, built around digitising the card game *Flip 7* (The Op Games).  
The aim of the project is to strengthen core front-end engineering skills — particularly **React**, **TypeScript**, and **modern UI architecture** — through the design of an interactive, data-driven web app.

This project represents both a creative outlet and a structured way to practice technical problem-solving.  
It includes implementing logic for game rules, state management, component reusability, and visual feedback (animations, scoring updates, etc.), while also exploring testing and accessibility best practices.

## Why It Matters

Flip 7 isn’t just a game project — it’s a **learning scaffold**.  
Each feature connects to a practical development skill: deck shuffling relates to data structures; score calculation to algorithmic thinking; and state persistence to React state management.  
The process of breaking complex problems into smaller parts mirrors the same skills I want to strengthen in my day-to-day engineering work.

Ultimately, this project documents my **growth as a developer** — moving from needing detailed step-by-step guidance to being able to reason through problems and build effective, maintainable code.
